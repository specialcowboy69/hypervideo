# Pizarra SEO y visibilidad en IA, versión 2

Prototipo autónomo de HyperFrames para el guion en `guion.md`. Usa la voz configurada en el proyecto, en una única locución de unos 75 segundos, y conserva el estilo de pizarra del prototipo anterior. No está integrado en el constructor de `data-lab` ni en la cola de vídeo.

Para reproducir el proyecto, generar el texto de `guion.md` con la voz configurada y guardar la locución como `assets/voice.mp3`. Instalar GSAP con `npm install`; el audio y el MP4 son archivos de producción ignorados por Git. Después ejecutar `npm run check` y `npm run render -- --output seo-aeo-pizarra-v2.mp4`.

Revisar inicio, comparación, PDF y cierre en los fotogramas de 4, 44, 62 y 71 segundos. Los tiempos de escena siguen el audio generado; para otra toma de voz hay que reajustar los cortes y la duración raíz.
